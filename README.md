Project Overview – 
I am building the "Type A Student Planner", an app designed specifically for college students who love high-structure organization and need to plan out every detail of their lives to feel ready for the day. While there are plenty of generic planner apps out there, none of them quite hit the mark for students who want a single place to track detailed academics alongside day-to-day life details like meals, habits, and appointments. My app bridges that gap by mixing traditional physical planner layouts with modern tech features, like auto-syncing a syllabus into a student's schedule and syncing assignments directly to their phone's calendar.
Data Layer -
The data layer acts as the backbone of the app, storing both academic information and daily personal tracking in a structured database. I am drawing inspiration from physical planners I have used or researched: Papier, The Daily, Plum Paper, and Day Designer, to structure tables for time-blocking grids, top daily priorities, class breakdowns, and habit tracking. The database organizes information by keeping separate lists (tables) for things like user profiles, classes, assignments, and daily habits, using shared ID tags to link them together, so an assignment automatically knows which class it belongs to. It also uses a temporary holding area for uploaded files, like a syllabus PDF or photo. This lets the app extract and clean up the dates and assignments first so the student can review them before everything gets saved into their actual planner database.
Processing Layer
The processing layer is where all the logic and automation happen to make the app smart. The biggest feature here is an AI-powered syllabus scanner that uses text recognition to read uploaded class syllabi, pull out assignment names, due dates, and grade percentages, and drop them into a quick review screen for the user to confirm. Once saved, the app uses API links to automatically push those assignments over to Google Calendar or Apple Reminders. It also runs a dynamic reminder system that sends alerts based on how big an assignment is, giving a week's notice for major exams versus a 24-hour heads-up for daily homework. Behind the scenes, background logic automatically rolls unfinished tasks over to the next day and pulls meals, habits, and classes into a daily summary so students don't have to re-enter info constantly.
Presentation Layer
The presentation layer covers what the app actually looks and feels like, focusing on a clean, visual design with color-coding per class and easy-to-read grids. The interface is split into three main time views: a Monthly View to see big exam dates and personal events, a Weekly View to balance school and life, and a Daily View that features an hourly time-blocking schedule along with other features as well. It also includes dedicated screens for individual class dashboards, a master assignment table you can filter by due date or grade weight, and a drag-and-drop syllabus upload screen where students can preview and edit data before adding it to their planner.
